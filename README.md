# ANGUNET landing page

Standalone HTML/CSS/JavaScript promotional website for [ANGUNET](https://github.com/saifii007/angunet).

The Download ZIP links point to the original ANGUNET source repository, not this landing-page repository. No build step is required.

## GitHub Pages
In Settings → Pages, select **GitHub Actions** as the source. The workflow publishes the repository root; `index.html` is at the root.

Expected URL: https://saifii007.github.io/angunet-site/
