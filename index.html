Quick start

Start with a single command.

Use Node.js 20 or newer for the ANGUNET CLI. Check the repository README for the latest requirements and detailed instructions.

Generate a project

npx angunet yapp my-app

Then open the generated project and follow its README to install dependencies and run it.
