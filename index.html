Quick start

Start with a single command.

Use Node.js 20 or newer for the ANGUNET CLI. Check the repository README for the latest requirements and setup instructions.

Generate a project

$ npx angunet my-app

Then open the generated project and follow its README to install dependencies and run it.

ANGUNET is an open-source project created to make starting full-stack applications with Angular and ASP.NET Core easier.

Why ANGUNET?

ANGUNET is built around a simple idea: getting a full-stack project started should feel easier. By bringing Angular, ASP.NET Core, and supporting developer tools together, the project aims to give developers a useful starting point instead of making everyone repeat the same setup work.

I’m sharing it as an open-source project so developers can explore the implementation, adapt it to their needs, and help it improve. If it’s useful to you, try it out, share feedback, or contribute on GitHub.
